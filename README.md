Minecraft Java **26.2**, NeoForge **26.2.0.93**, Java **25**. Remplacer le précédent JAR TND dans `mods/`, côté client et serveur. Explorer des **chunks inexplorés** pour trouver les nouvelles métropoles et leurs laboratoires. Les constructions déjà enregistrées ne sont pas remplacées.

Cette version comprend des métropoles continues d’environ 1 280 blocs de diamètre sous dôme traversable, une couronne de pics ferrenoirs, un laboratoire unique par ville, un familier personnel avec trois formes et quatre aptitudes, son dossier et ses capsules de transport, un portail plus clair, des ancres alimentées pour les usines et une conclusion scénaristique jouable. L’industrie, les machines, les équipements, les créatures et les quinze maîtrises des versions précédentes restent inclus.

Les cinq onglets se trouvent **à gauche de l’inventaire**. Le bouton **Familier** est également disponible dans les paramètres. Pour le portail, **Inventaire → ? → Portail** explique le moniteur, ses huit charpentes, ses quatre relais, les 16 000 FE et le cristal composite.

La conclusion utilise une dimension isolée et des journaux de récupération conservés. **`/tnd recover`** permet de récupérer sa propre session interrompue. Le guide décrit les choix et le retour ; sa dernière partie révèle l’histoire.

Versions précédentes conservées : [0.11 Nacre-9](tnd-0.11.0-dev.jar) · [0.10 industrielle](tnd-0.10.0-dev.jar) · [0.9](tnd-0.9.0-dev.jar). Leurs guides et galeries restent disponibles.
