Placer le JAR dans le dossier `mods/` de votre instance, en remplaçant l’ancienne version TND. Les maîtrises et constructions existantes sont conservées. Explorer **de nouveaux chunks de Vestige** pour découvrir l’observatoire.

Le nouvel onglet sous les maîtrises dans l’inventaire ouvre les expéditions : voyages, réparations, récoltes nocturnes, combats et récompenses personnelles. Les notes de voyage commencent avec cette version ; l’équipement résonant déjà possédé est reconnu.

Lier le prisme à une ancre dans Vestige, puis maintenir son utilisation cinq secondes sans bouger pour revenir. Coût : deux poussières d’écho après une arrivée réussie ; recharge : une minute. Le guide contient les recettes et les règles d’annulation.

Cette version conserve les six biomes, les ambiances et les 24 sons, les maîtrises, les minerais affleurants, les grandes structures aménagées, le familier, les épreuves, le Conservateur brisé et la forge de la 0.7. Les huit nouveaux blocs et le prisme utilisent aussi des textures 16 × 16.
