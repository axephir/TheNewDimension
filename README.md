Minecraft Java **26.2**, NeoForge **26.2.0.93**, Java **25**. Remplacer le précédent JAR TND dans `mods/`. Explorer de nouveaux chunks pour trouver les villes. Les anciennes liaisons de portail sont conservées ; ajouter un moniteur assemblé côté Overworld pour repartir. Le retour depuis Vestige reste disponible.

Le portail animé exige un moniteur : huit charpentes au niveau inférieur, quatre bobines de relais au niveau du moniteur, 16 000 FE et un cristal composite pour la première ouverture. **Inventaire → ? → Portail** explique le montage. Les archives s’ouvrent depuis le quatrième onglet à gauche.

Nacre-9 ajoute des quartiers de huit tours, trois ennemis hostiles jour et nuit, huit archives personnelles, treize blocs et douze sons originaux. Les neuf machines et réseaux énergétiques de la 0.10 restent inclus.
