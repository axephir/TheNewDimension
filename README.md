Copier le JAR dans le dossier `mods/` de votre instance NeoForge en remplaçant l’ancien JAR TND. Les versions précédentes restent archivées sur cette branche.

Après les trois épreuves du sanctuaire, récupérer le cœur, puis tenir de la poussière d’écho et cliquer sur le noyau : deux poussières éveillent le Conservateur brisé. Les sanctuaires terminés dans les anciennes versions sont compatibles. Sa matrice sert à fabriquer la forge résonante.

Cette version ajoute le boss facultatif, quatre transformations industrielles, une pioche et une lame, cinq progrès, six sons et leurs sous-titres. Les biomes, ambiances et célébrations de maîtrise de la 0.6 restent inclus.
