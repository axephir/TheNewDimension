Minecraft Java **26.2**, NeoForge **26.2.0.93**, Java **25**. Copier le JAR dans `mods/` et retirer l’ancienne version TND. Les neuf machines et leurs infrastructures se construisent dans les sauvegardes existantes. **Inventaire → Guide → Industrie** explique chaque installation.

La carrière exige un derrick, de l’énergie et des trépans. Elle retire réellement le terrain sous elle uniquement après activation : choisir son emplacement avant de démarrer.

La 0.9 reste incluse. Ses nouvelles structures apparaissent dans de nouveaux chunks ; les bâtiments déjà générés sont conservés. Les versions précédentes restent disponibles : [0.9](tnd-0.9.0-dev.jar), [galerie 0.9](GALLERY_0.9.0.md), [0.8](tnd-0.8.0-dev.jar).
