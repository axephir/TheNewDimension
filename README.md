# The New Dimension — prototype 0.1.0-dev

Minecraft Java 26.2, NeoForge 26.2.0.93, Java 25.

Cette branche sert au téléchargement du prototype. Le cahier des charges complet et les validations en jeu ne sont pas terminés. Utiliser un nouveau monde de test.

Télécharger `tnd-0.1.0-dev.jar` avec le bouton de téléchargement du fichier, puis le placer dans le dossier `mods` du profil NeoForge.

Commandes : `/tnd enter`, `/tnd leave`, `/tnd masteries`.
